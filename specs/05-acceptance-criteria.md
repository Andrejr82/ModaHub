# Acceptance Criteria

- A home deve comunicar ModaHub como streetwear premium multimarcas.
- Header deve exibir topbar, busca, menu comercial, wishlist, WhatsApp e carrinho.
- Hero deve ter campanha de nova coleção, CTAs e badges comerciais.
- ProductCard deve mostrar marca, nome, categoria/subcategoria, tamanhos, preço, preço antigo, desconto, frete grátis, estoque, rating, parcelamento, wishlist e botão Comprar/Esgotado.
- Carrinho deve mostrar itens, tamanho, quantidade, remover, subtotal, cupom, CEP, frete grátis progressivo, desconto mockado, total e CTAs.
- Footer deve ter institucional, ajuda, contato, redes, pagamento, envio e copyright demo.
- Busca, filtros, ordenação, wishlist e carrinho devem permanecer funcionais.
- Validações: npm run lint, npm run typecheck, npm run test e npm run build.
