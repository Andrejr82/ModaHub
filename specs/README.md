# Specs

## Objetivo

Esta pasta reúne as especificações funcionais e técnicas do ModaHub.

## Ordem de leitura

1. `01-product-spec.md` — visão do produto.
2. `02-ux-ui-spec.md` — estrutura e direção de UX/UI.
3. `03-technical-spec.md` — arquitetura técnica.
4. `04-data-contract.md` — contratos e estrutura dos dados.
5. `05-acceptance-criteria.md` — critérios de aceite.
6. `06-test-harness.md` — validação e checks esperados.
7. `07-implementation-audit.md` — auditoria do estado implementado.

## Regra de manutenção

Atualize os arquivos desta pasta sempre que a alteração mudar produto, UX, dados, arquitetura ou critérios de aceite.
